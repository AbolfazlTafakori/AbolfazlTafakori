<h2 align="left">About me</h2>

<p align="left">
What I enjoy is <b>the whole system</b> rather than a single endpoint — designing the data model, wiring up authentication, and getting the thing running on a real server behind nginx.
<br/><br/>
Almost everything I build is self-hosted. My projects ship with a one-command installer, an admin panel for managing content, and backup and restore built in — software people can run and own themselves is more useful to me than software they can only rent.
</p>
